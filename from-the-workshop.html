The Wizard Central Toolkit — free, local-first, mine

The Wizard Central Toolkit (Apache 2.0, version 0.2.8) is a local-first command-line toolkit: a router — the Wizarding Router — plus 12 specialist wizards, 147 subcommands in all, running entirely on your own machine. Nothing leaves your computer; that's the design, not a setting.

Install it with one command:

pip install wizard-central-toolkit

Get it on PyPI View the code on GitHub

The toolkit's official home is GitHub and PyPI — this page is my article about it, on my own site. The full showcase — the fleet, the 147 subcommands, and the rules it lives by — is on the MathSphere Nexus site.

Wizard Central Pro AI Modes Toolkit is in development and not yet available: a gate between a person and their AI models, where every tool call a model makes crosses one checkpoint — the person grants access, reviews what the model proposes, and approves anything that matters.
